# Studying with and without AI

AI Culture final project, Track A.

- `main.ipynb` builds the SQLite database in memory, loads 11 published results from two randomized trials, and runs six queries with a Mermaid ER diagram and Matplotlib charts. Open it in Jupyter and run all cells with Python 3, SQLite 3.37+ and Matplotlib 3.7+. Saved outputs are included.
- `report.docx` explains the data, schema, findings and limitations.
- `presentation.pptx` summarizes the project in seven slides.

Sources: [Bastani et al., high school mathematics](https://doi.org/10.1073/pnas.2422633122) and [Kestin et al., university physics](https://doi.org/10.1038/s41598-025-97652-6).
